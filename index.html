          About the public edition

          A reading gateway to mathematics resources.

          Catalog and synchronization

          The public catalog is built from local bibliographic records using the same classification rules. Each publication updates the existing pages and catalog in place. The date in the masthead identifies the latest catalog update.

          Public scope

          Public entries contain titles, authors, subjects, resource types, years, languages and original sources. Personal notes, OneNote pages, local paths and local application services are excluded.

          Read local PDFs

          Connect your MathKnowledge folder to open matching PDFs directly on this computer. Your browser asks for read permission. If books are stored on another drive, connect their containing storage folder too. Folder access lasts for this page and can be disconnected. No PDFs or local catalog data are uploaded. Other visitors cannot read files on your computer; they can follow the public source links.

          Mathematics in titles

          Title formulas are rendered locally with KaTeX and native MathML. The original searchable title is preserved. KaTeX is distributed under its MIT license.

          Knowledge desk

          On the live library, the knowledge desk lists mathematical concepts with a short note, a formula, the concepts to read first and the shared PDFs on each one. The notes are written by Formosa. Banana Space links open a search on that site; its articles are not imported and its live API is not connected.

          Live public library

          The live library supports direct PDF reading, full-text search, indexed page excerpts, book details, reading paths and a browser-local bookshelf. Only owner-selected PDFs are served or searched. Sharing settings are managed from a separate control page on the owner's computer. The computer and tunnel must remain online; free tunnel addresses can change.

          Sources and use

          Source links lead to authors, universities, publishers or public repositories. Check editions, errata and usage terms; public access does not grant redistribution rights. This independently curated catalog is not endorsed by the listed authors or institutions.
