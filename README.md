# Formosa public mathematics catalog

Read-only bibliographic metadata and original source links. No local files, personal notes, OneNote content, credentials, or backend endpoints are included.

The public interface uses English. Bibliographic titles and author credits are shown as published in the catalog.

The linked live library provides the Knowledge desk and reading routes. They require the live read-only backend; GitHub Pages serves the static catalog.

To read your own PDFs, use **Connect local library** and select your MathKnowledge folder. For books on another drive, connect their containing storage folder too. Folder access is read-only and no files are uploaded. Other visitors use their own files or the public source links.

Titles and reading text render Markdown and LaTeX with the bundled Markdown parser and KaTeX renderer using native MathML output. See [KaTeX MIT license](katex-LICENSE.txt) and [Markdown-it MIT license](markdown-it-LICENSE.txt).
